# letter-c.m4a — the letter “c”

| | |
|---|---|
| **Save the recording as** | `letter-c.m4a` (or `letter-c.wav`, see the [README](README.md)) |
| **Sound to record** | **/k/** — said like “k” |
| **Example word** | cat (the app says this separately: “…like in cat”, so don't record it) |
| **Type** | stop sound |
| **Length** | 0.2–0.5 seconds. Short and crisp; end cleanly. |

## Say this
The letter C makes the hard “k” sound here, as in “cat”: a quick “k”.

## Don't say this
Not “see”. Not the soft c (“s”).

## Checklist

- [ ] Same voice, distance and volume as the other files
- [ ] Saved with exactly the file name above, then placed in `ios/SightWords/Resources/Sounds/`
