# letter-b.m4a — the letter “b”

| | |
|---|---|
| **Save the recording as** | `letter-b.m4a` (or `letter-b.wav`, see the [README](README.md)) |
| **Sound to record** | **/b/** — said like “b” |
| **Example word** | bear (the app says this separately: “…like in bear”, so don't record it) |
| **Type** | stop sound |
| **Length** | 0.2–0.5 seconds. Short and crisp; end cleanly. |

## Say this
A quick buzz of the lips: “b”. Keep any “uh” tiny.

## Don't say this
Not “bee”. Not “buh” with a long vowel.

## Checklist
- [ ] Only the sound — no letter name, no word, no extra “uh” beyond what's described above
- [ ] Starts within about 50 ms of the beginning (trim leading silence), ends cleanly with no breath or click
- [ ] Same voice, distance and volume as the other files
- [ ] Saved with exactly the file name above, then placed in `ios/SightWords/Resources/Sounds/`
