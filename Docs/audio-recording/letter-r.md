# letter-r.m4a — the letter “r”

| | |
|---|---|
| **Save the recording as** | `letter-r.m4a` (or `letter-r.wav`, see the [README](README.md)) |
| **Sound to record** | **/r/** — said like “r” |
| **Example word** | rainbow (the app says this separately: “…like in rainbow”, so don't record it) |
| **Type** | continuous sound |
| **Length** | 0.6–1.0 seconds. Hold the sound steady; it should not fade out or change. |

## Say this
A growly “rrrrr” with the tongue pulled back, lips slightly rounded.

## Don't say this
Not the letter name “are”. Not “ruh” with a heavy vowel.

## Checklist
- [ ] Only the sound — no letter name, no word, no extra “uh” beyond what's described above
- [ ] Starts within about 50 ms of the beginning (trim leading silence), ends cleanly with no breath or click
- [ ] Same voice, distance and volume as the other files
- [ ] Saved with exactly the file name above, then placed in `ios/SightWords/Resources/Sounds/`
